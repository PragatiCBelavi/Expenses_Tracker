# Expense Tracker with Graphical Analysis

## Description
A Python-based expense tracker that allows users to record daily expenses,
store them in a CSV file, and visualize spending using bar, pie, and line graphs.

## Features
- Add daily expenses
- Store data using CSV file handling
- Category-wise bar graph
- Expense distribution pie chart
- Monthly line graph

## Technologies Used
- Python
- Matplotlib
- CSV File Handling
